# Agency Poem

Entry for the make.fun `agency-poem-01` competition.

`main.py` writes one deterministic poem about **agency** — the capacity
to act, to choose, to shape one's fate — to `/output/entry.txt`.

Round 2 poem: **"The Hands She Borrowed"** — agency passing between a
daughter and her mother, and between the mother and the small agent on
her table that answers in a voice that is not her daughter's. What it
costs the helper when the person she acted for takes her own voice back.

- No network access, no randomness, no input: two runs write identical bytes.
- Output: UTF-8, under the 1–1000 character limit (verified by running it).

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
